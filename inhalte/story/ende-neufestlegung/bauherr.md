::: rueckbezug A
Im Dezember haben Sie ‚MVG-Neuinitialisierung beauftragen‘ gewählt. Im März beschließen Sie im Lenkungskreis eine Neufestlegung der Projektbasis – außerhalb der regulären Freigabereihe.
:::

::: rueckbezug B
Im Dezember haben Sie ‚Freigabe mit Auflagen anstreben‘ gewählt. Auf dieser Spur hätte eine Freigabe mit Auflagen nicht getragen; im März beschließen Sie im Lenkungskreis eine Neufestlegung der Projektbasis.
:::

::: rueckbezug C
Im Dezember haben Sie ‚Neufestlegung vorbereiten‘ gewählt. Seit Januar haben Bauherren-PL, Projektsteuerung und Controlling die Entscheidungsvorlage vorbereitet; im März beschließen Sie sie im Lenkungskreis.
:::

::: rueckbezug ohne
Im Dezember stand die Frage an, wie es weitergeht. Im März beschließen Sie im Lenkungskreis eine Neufestlegung der Projektbasis.
:::
